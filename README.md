# Proof Checked Agent Lab

This is a planned learning project with no implementation yet.

The goal is to check AI generated proof attempts with a proof assistant and record accepted proofs, errors, and timeouts.

## Plan

1. Start with small examples.
2. Add a Python runner to send proof attempts to the proof assistant.
3. Save evaluation results, including accepted proofs, errors, and timeouts.

No evaluation results are available yet.
